# 👋 ¡Bienvenidos! a mi proyecto bloc de recordatorio
<img src="imagen_presentacion.png" alt="Presentación" width="220" align="left" style="margin-right: 20px; border-radius: 5px;">

<p style="text-align: justify;">
    ¡Bienvenido a este repositorio! Aquí presento mi <b>Bloc de recordatorio</b>, un proyecto diseñado para gestionar notas digitales mediante una interfaz moderna e intuitiva. El núcleo de este ejercicio práctico fue el desafío de replicar la misma lógica de negocio en múltiples entornos (<b>Pseint, Python, Java y Visual Basic</b>), permitiéndome comparar sintaxis, rendimiento y estructuras de desarrollo tanto en consola como en aplicaciones de escritorio bajo el enfoque de la programación orientada a objetos.
</p>

<p style="text-align: justify;">
    Además, logré una integración completa entre desarrollo <b>frontend</b> (html, css, js) y <b>backend</b> (php, phpmyadmin), manipulando dinámicamente el dom y conectando la interfaz mediante peticiones asíncronas para garantizar una persistencia de datos híbrida: de forma local e inmediata con <b>localstorage</b>, y de manera centralizada en una base de datos relacional mediante un servidor local en <b>xampp</b>. El intercambio de información entre el cliente y el servidor se estructuró rigurosamente utilizando el formato estándar json, lo que facilitó operaciones crud completamente fluidas y en tiempo real. Asimismo, diseñé un panel resumen con métricas dinámicas que reflejan el progreso de los estados (pendiente, en progreso y completado) de cada alerta. Todo este ecosistema web fue desarrollado de forma nativa y sin frameworks, logrando una interfaz adaptativa y responsiva que demuestra el dominio técnico de las bases del desarrollo de software.
</p>

#
### ✨ Características del proyecto
* Diseño moderno, minimalista y responsivo inspirado en un bloc de recordatorios físicos.
* Gestión dinámica, organizada y categorizada de recordatorios.
* Almacenamiento local híbrido usando <b>localstorage</b> para persistencia rápida en el navegador.
* Integración completa y fluida entre componentes <b>frontend</b> y <b>backend</b>.
* Implementación de bases de datos relacionales utilizando <b>xampp y phpmyadmin</b>.
* Operaciones crud (crear, leer, actualizar, borrar) completamente funcionales en múltiples lenguajes.
* Actualización de la interfaz en tiempo real tras interactuar con los datos.
* Sistema de progreso y estados para los recordatorios:
    * Pendiente
    * En progreso
    * Completado
* Panel de resumen estadístico con métricas dinámicas del estado de los recordatorios.
* Manipulación dinámica del dom usando javascript puro, desarrollado <b>sin frameworks</b> para entender las bases del desarrollo web.
* Estructura limpia y organizada de archivos, segmentada por lenguaje y tecnología utilizada.
* Enfoque netamente orientado al autoaprendizaje, experimentación y robustecimiento de habilidades full-stack.

#
### ⚙️ Funcionalidades implementadas
* Creación y almacenamiento de recordatorios diarios.
* Edición dinámica de notas existentes.
* Eliminación e historial de recordatorios borrados.
* Sistema de prioridades (alta, media, baja) para un control eficiente.
* Clasificación por categorías o etiquetas temáticas.
* Control estricto de los estados de progreso de cada alerta.
* Resumen estadístico visual del rendimiento y cumplimiento de tareas.
* Persistencia nativa de datos utilizando el navegador web mediante <b>localstorage</b>.
* Persistencia robusta y centralizada de datos usando bases de datos en <b>phpmyadmin</b>.
* Conexión síncrona/asíncrona entre la interfaz frontend y el backend.
* Intercambio y manejo de datos estructurados utilizando el formato estándar <b>json</b>.
* Interfaz adaptativa (responsive design) apta para dispositivos móviles, tablets y ordenadores.
